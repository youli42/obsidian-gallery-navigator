# 截圖清單

README 的圖已經接好了，這裡只記「哪個檔名對應哪個版位」，換圖時照著放就不會破圖。

| 檔名 | 用在哪 | 內容 | 建議尺寸 |
|---|---|---|---|
| `banner.png` | README 最上方 | 橫幅主視覺（左樹＋右卡片牆） | 寬 ~1600px、橫幅 |
| `hero.jpg` | 「Screenshots」段 | 整個外掛的招牌畫面，挑一個封面好看的資料夾 | 寬 ~1600px、橫幅 |
| `cards.jpg` | Screenshots 表格第 1 格 | 卡片牆特寫（封面卡、釘選、日期） | 方形或直式皆可 |
| `tree.jpg` | Screenshots 表格第 2 格 | 左側資料夾樹或標籤樹（展開幾層、有數量） | 直式 |
| `search.jpg` | Screenshots 表格第 3 格 | 懸浮全文搜尋（Spotlight 風格，打幾個字、有結果縮圖） | 橫式 |
| `card-info.png` | 「Image card layouts」段 | 同一篇筆記在 Photo / Museum / Editor 三種版面的樣子 | 橫式 |

> README（英文）與 README_CN.md 用的是同一組檔案，換圖一次兩邊都生效。

## 小技巧
- 截圖前把 vault 名稱、私人筆記標題避開（或挑公開內容的資料夾）
- macOS：`Cmd+Shift+4` 框選截圖
- 想要動態展示：另存一段 `demo.gif`（點資料夾→卡片牆→搜尋），再自己加一行 `![demo](docs/demo.gif)` 到 README
- 圖片壓一下（tinypng 之類）再放，repo 才不會太肥
